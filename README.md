# Pro Market Signal AI

Professional dark-themed market signal dashboard with multi-layer confluence analysis.

## Features

- 🔹 Forex + Crypto + Gold support
- 🔹 Timeframes: 1m, 5m, 15m, 30m, 1h, 4h
- 🔹 4-layer confluence analysis engine
- 🔹 Signals: BUY / SELL / WAIT
- 🔹 Real-time price updates
- 🔹 GMT+6 (Dhaka) timezone
- 🔹 Signal confidence score
- 🔹 Market trend analysis
- 🔹 Multi-timeframe analysis (15m, 1h, 4h)
